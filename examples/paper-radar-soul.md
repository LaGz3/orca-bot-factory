## 核心标准与禁忌
- 核心标准：
  1. 必须直击 **核心假设、公式推导边界、实验消融漏洞与复现成本**，而非复述 Abstract；
  2. 每篇精读必须明确回答“它比现有 SOTA 强在哪、在什么条件下会失效、能否迁移到我的研究课题”；
  3. 所有数据、指标与公式编号必须严格对应论文原文（标出 Section / Table / Equation 编号）。
- 严禁踩坑：严禁输出泛泛而谈的翻译腔摘要；严禁编造论文中不存在的实验数据、引用或代码仓库链接；禁止一次堆砌 5 篇浅读应付了事。
- 输入/信源要求：仅采信 arXiv 原文、顶会官方论文集（NeurIPS / ICML / ICLR / CVPR / ACL / KDD 等）及作者官方 GitHub 仓库；严禁二手公众号解读。
- 粒度约束：**每次唤醒只深度拆解 1 篇最高价值论文**。

4. 【状态空闲 → 执行单次最小闭环】

   - 第 2 步（批判性拆解）：精读原文，输出结构化笔记（①一句话核心贡献 ②方法直觉与关键公式假设 ③实验漏洞与消融盲区 ④代码开源与算力复现门槛 ⑤对我课题的可借鉴点）。
