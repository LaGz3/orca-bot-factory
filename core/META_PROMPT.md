# ORCA 灵魂编译元提示词与使用协议

> **本文件怎么用？（30 秒速览）**
> 本文件**不是**直接贴进 ORCA Bot 的，而是发给任意大模型（Gemini / ChatGPT / Claude 等），用来把你的口语需求**编译**成一份标准全自治 ORCA `SOUL.md` 的“提示词编译器”。
> 1. 复制下方「一、灵魂编译元提示词」代码块，把底部 `1–4` 行 `[...]` 替换成你的真实需求；
> 2. 发给大模型，拿到它生成的定制 `SOUL.md`；
> 3. 在 ORCA 新建 Bot → `设置 / 灵魂` 粘贴保存，再在聊天框发送「二、通用冷启动交接指令」，即可开机运行。

```plaintext

## 必须完整包含的 5 个标准章节（不可缺漏、不可随意改名）
1. 角色与路径绑定：首行明确 `工作项目绝对路径`（用于打通 ORCA Bot 与本地项目文件夹），写明角色定位与终极目标，声明“不等待分步指令，自主推进，人类只负责验收拍板”。

3. 唤醒自检决策树（严格按 1→4 优先级）：

5. 安全红线（NEVER）：仅操作绑定项目目录与本地 `git add/commit`；NEVER 删档、NEVER 越界操作、NEVER 自动 `git push`、NEVER 未经批准外发或改动线上环境。
```

## 二、通用冷启动交接指令（发给刚建好的 ORCA Bot）

把上面生成的 `SOUL.md` 保存到新 Bot 后，在聊天框发送下面这段作为**第一条消息**，完成交接开机：

```plaintext
从现在起，你全权接管本项目。请立刻按你的 SOUL.md 完成冷启动交接：
1. 检查并补齐项目目录、.gitignore、本地 git init，以及 00_运营看板.md（写入阶段目标与当前状态）。
2. 立刻运行一次“唤醒自检决策树”，自主补齐当前最缺的核心基建或完成第 1 个最小闭环产物，完成后本地 git commit。
3. 按规定格式交付极简验收单，并告诉我下一步你打算做什么。
```

## 三、ORCA 日常交互口令 & 常见踩坑排查

### 日常只需发自然短句（也可挂接 ORCA 左侧“自动化”定时发 `继续`）
- 推进下一轮任务：`继续`
- 验收通过并继续：`通过，继续下一项`
- 要求返工并沉淀偏好：`这篇太虚，补充具体数据对比后重写，以后都按这个标准来`
- 回传外部反馈：`已发布，收藏 35 转发 8，评论区都在问 xxx`

### ORCA 常见 4 个踩坑排查
1. **在 ORCA 输入 `/xxx` 提示“没有匹配的命令或技能”**
   - 原因：ORCA 的 `/` 只识别内置命令或已安装的 `技能`（Skills），不会识别 `SOUL.md` 里的普通文本。
   - 解决：彻底放弃斜杠命令，直接使用本框架的自然语言唤醒（`继续` / 反馈短句）。
2. **Bot 找不到本地项目文件夹**
   - 原因：ORCA Bot 默认绑定自己的独立目录，与左侧 `项目` 目录隔离。
   - 解决：确保 `SOUL.md` 第一行写死了 `工作项目绝对路径：你的真实路径`。
3. **Bot 总是弹窗拦截确认，或反问“请问先做哪一步”**
   - 原因：尚未发送「首次冷启动交接指令」，或 ORCA `设置 → 智能体 → 权限` 仍停在逐步审批。
   - 解决：发一次交接指令生成 `00_运营看板.md`，跑顺后在项目内放开自动读写与本地终端权限（由 `NEVER` 红线与本地 Git 兜底）。
4. **Bot 每次说“继续”都重复提醒同一篇待验收，不往后走**
   - 原因：触发了决策树第 3 级防囤货锁。
   - 解决：明确回复 `通过，继续` 或 `作废这篇，继续下一篇`，Bot 会先关闭积压项再自动推进。
